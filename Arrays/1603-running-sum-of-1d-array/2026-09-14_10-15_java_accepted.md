## Solution

```java
class Solution {
    public int[] runningSum(int[] nums) {
        int n = nums.length;
        int[] result = new int[n];

        int sum = 0;
        for(int i = 0; i < n; i++){
            sum = sum + nums[i];
            result[i] = sum;
        }
        return result;
    }
}
```
