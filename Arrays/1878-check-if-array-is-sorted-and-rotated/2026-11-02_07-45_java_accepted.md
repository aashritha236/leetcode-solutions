## Solution

```java
class Solution {
    public boolean check(int[] nums) {
        int cnt = 0;
        int n = nums.length;

        if(n < 2)   return true;

        for(int i = 0; i < nums.length; i++){
            if(nums[i] > nums[(i + 1) % n] ){
                cnt++;
            }
            if(cnt > 1)
                return false;
        }
        return true;
    }
}
```
