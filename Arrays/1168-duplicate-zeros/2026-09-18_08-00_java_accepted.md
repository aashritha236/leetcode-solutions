## Solution

```java
class Solution {
    public void duplicateZeros(int[] arr) {  
        int n = arr.length;
       
        //shifting elements to store another 0 wherever we find one
        for(int i = n-1; i >= 0; i--){
            if(arr[i] == 0 && i != n - 1){
                for(int j = n - 1; j > i; j--){
                    if(j != n - 1)
                        arr[j+1] = arr[j];
                }
                arr[i+1] = 0;
            }
        }
        return;
    }
}
```
