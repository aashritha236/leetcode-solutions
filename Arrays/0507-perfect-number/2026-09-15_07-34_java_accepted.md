## Solution

```java
class Solution {
    public boolean checkPerfectNumber(int num) {
        int sum = 0;
        int temp = num;
        int i = 1;
        while(i <= num/2){
            if(num % i == 0)
                sum+= i;
            i++;
        }
        return (num == sum)? true:false;
         
    }
}
```
