## Solution

```java
class Solution {
    public boolean checkPerfectNumber(int num) {
        if(num % 10 != 8 && num % 10 != 6)
            return false;

        int sum = 0;
        int temp = num;
        int i = 1;
        while(i <= num/2){
            if(num % i == 0)
                sum+= i;
            i++;
        }
        return (num == sum)? true:false;
         
    }
}
```
