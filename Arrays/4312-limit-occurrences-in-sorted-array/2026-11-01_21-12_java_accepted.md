## Solution

```java
class Solution {
    public int[] limitOccurrences(int[] nums, int k) {
        int j = 0, cnt = 1;
        int[] res = new int[nums.length];

        if(nums.length == 0 || k == 0)
            return res.length == 0 ? res : new int[0];
        res[j++] = nums[0];

        for(int i = 1; i < nums.length; i++){
            if(nums[i] == nums[i - 1]){
                cnt++;
            }
            else
                cnt = 1;

            if(cnt <= k)
                    res[j++] = nums[i];
        }
        return Arrays.copyOf(res, j);
    }
}
```
