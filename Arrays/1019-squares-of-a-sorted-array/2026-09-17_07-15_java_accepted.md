## Solution

```java
class Solution {
    public int[] sortedSquares(int[] nums) {
        int left = 0;
        int n = nums.length;
        int right = n-1, pos = n-1;
        int[] cp = new int[n];
        
        while(left <= right){
            int leftsqr = nums[left]*nums[left];
            int rightsqr = nums[right]*nums[right];
            
            if(leftsqr > rightsqr){
                cp[pos] = leftsqr;
                left++;
            }
            else{
                cp[pos] = rightsqr;
                right--;
            }
            pos--;
        }
        return cp;
    }
}
```
