## Solution

```java
class Solution {
    private int findDigits(int num){
        int count = 0;

        while(num != 0){
            count++;
            num /= 10;
        }
        return count;
    }

    public int findNumbers(int[] nums) {
        int count = 0;

        for(int i = 0; i < nums.length; i++){
            int digits = findDigits(nums[i]);
            if(digits % 2 == 0)
                count++;
        }
        return count;
    }
}
```
