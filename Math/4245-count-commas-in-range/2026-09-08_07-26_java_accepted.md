## Solution

```java
class Solution {
    public int countCommas(int n) {
        int c = 1;
        int totalcommas = 0;
        int temp = n;

        int start = 1000;
        while(start <= n){
            int end = start * 1000 -1;
            if(end > n)
                end = n;

            int val = end - start + 1;
            totalcommas += val * c; 
            start = start * 1000;
            c++;
        }
        return (int)totalcommas;
    }
}
```
