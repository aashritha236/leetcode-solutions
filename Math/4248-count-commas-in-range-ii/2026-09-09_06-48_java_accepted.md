## Solution

```java
class Solution {
    public long countCommas(long n) {
        long totalCommas = 0;
        long commasPerNum = 1;
        long start = 1000;
        
        while(start <= n){
            long end = start * 1000 - 1;
            if(end > n)
                end = n;
            long val = end - start + 1;
            totalCommas += val * commasPerNum;
            start = start * 1000;
            commasPerNum++;
        }
        return totalCommas;
    }
}
```
