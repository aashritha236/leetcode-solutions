## Solution

```java
class Solution {
    public int heightChecker(int[] heights) {
        int indices = 0;
        int n = heights.length;
        int[] expected = Arrays.copyOf(heights, n);
        
        for(int i = 0; i < n; i++){
            for(int j = 0; j < n-i-1; j++){
                if(expected[j] > expected[j+1]){
                    int temp = expected[j];
                    expected[j] = expected[j+1];
                    expected[j+1] = temp;
                }
            }    
        }
        
        for(int i = 0; i < n; i++){
            if(heights[i] != expected[i])
                indices++;
        }
        return indices;
    }
}
```
