## Solution

```java
class Solution {
    public int maxProduct(int n) {
        int product = 1;
        int temp = n;
        
        int len = String.valueOf(n).length();
        int[] digits = new int[len];

        for(int i = len-1; i >= 0; i--){
            digits[i] = temp%10;
            temp /= 10;
        }

        //traversing and calculating the sum of 2 digits in the number
        int count = 0;
        int max = 0;

        for(int i = 0; i < len-1; i++){
            for(int j = i+1; j < len; j++){
                product = digits[i]* digits[j];
                if(max < product)
                max = product;
            }          
        }
        return max;
    }
}
```
